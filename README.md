# 三餐四季菜品汇总（第一季 + 第二季 + 第三季）

央视《三餐四季》第一、二、三季出现过的菜品汇总网页，共 **50 道菜**（第一季 16、第二季 16、第三季 18），覆盖 22 个省份。

打开 **三餐四季菜品汇总.html** 即可使用，单文件、图片全部内嵌为 base64，离线也能看。

## 每道菜包含

- 菜品图片
- 家常做法：食材精确到克/毫升，时间精确到分钟，火候标注大火/中火/小火与温度区间
- 节目出处链接（央视网 / 百科 / 官方视频章节）

## 说明

- 图片来自网络检索（含央视节目相关照片），仅作菜品识别参考。
- 做法是按节目呈现与当地传统做法整理的**家常复刻版**，非官方配方，页面上也已注明。
- `dishes_all.json` 是全部菜品结构化数据（含分类字段），方便二次加工。
